## 📖 Course Description

A comprehensive study of embedded system organization, System on Programmable Chip (SoPC) technologies, and Real-Time Systems (RTS). The course focuses on the hardware-software co-design of embedded applications using the **ARM Cortex-M3** architecture. Key topics include Real-Time Operating Systems (RTOS), preemptive and non-preemptive scheduling algorithms (RMS, EDF), priority inversion handling, and embedded software specifications using SystemC.

## 🛠 Technical Competencies

Demonstrated engineering principles through the coursework include:

* **Real-Time Systems (RTS):** Application of RTOS kernels (Keil RTX) for task management, inter-process communication, and resource sharing.
* **Scheduling Algorithms:** Implementation and analysis of Preemptive, Non-Preemptive, Rate-Monotonic (RMS), and Earliest-Deadline-First (EDF) scheduling.
* **Embedded Architecture:** Low-level programming of the **ARM Cortex-M3** processor, including interrupt handling and peripheral interfacing.
* **Hardware-Software Co-Design:** Optimizing system performance through efficient partitioning of hardware and software components.
* **Fault Tolerance:** Strategies for designing robust systems capable of handling faults and priority inversion scenarios.
